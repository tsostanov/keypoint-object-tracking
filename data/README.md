# Входные видео

Добавленные материалы собраны в папке `data/videos/`:

| Файл | Что это |
| --- | --- |
| `mona-lisa.avi` | Исходная сцена с репродукцией Моны Лизы |
| `mona-lisa-blur.avi` | Вариант той же сцены с размытием |
| `mona-lisa-blur-extra-credit.avi` | Дополнительный вариант той же сцены с размытием |
| `test_cv.mp4` | Собственная съёмка обложки с рисунком, 720×1280, около 15 секунд |

Тестовые AVI хранятся локально и исключены из Git. Они не загружаются автоматически.
Собственное видео `test_cv.mp4` включено в материалы отчёта вместе с результатом обработки.

Для собственного видео используйте плоский прямоугольный объект с различимыми
деталями: например, книгу с рисунком на обложке или открытку с текстом.
Первый кадр должен быть крупным, резким и показывать все четыре угла.
После этого перемещайте объект, поворачивайте его, меняйте расстояние и умеренно
наклоняйте. На несколько кадров полностью уберите объект, затем верните его,
чтобы проверить LOST и восстановление. Снимайте при равномерном свете, без бликов.

Из корня проекта:

```powershell
python main.py --input data/videos/mona-lisa.avi --output results/videos/mona-lisa_tracked.mp4 --label "Mona Lisa"
```

Три исходных ролика и собственная съёмка проверены. Все четыре обработанных MP4
включены в Git и находятся в `results/videos/playback/`.
Обычный исходник и `blur` отличаются только на кадрах 10–35 из 558;
`extra-credit` показывает ту же сцену, но отличается на всех кадрах.
Подробности сравнения и ссылки на результаты — в основном README.

Повторная обработка собственного видео с сохранёнными углами:

```powershell
python main.py --input data/videos/test_cv.mp4 --output results/videos/test_cv_tracked.mp4 --selection results/videos/test_cv_selection.json --no-preview --label Cover
```
