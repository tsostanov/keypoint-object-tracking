# Входные видео

Положите в эту папку материалы преподавателя `test_1.mp4`, `test_2.mp4`,
`test_3.mp4` и самостоятельно снятый ролик `own.mp4`. В исходном репозитории
этих видео нет. Они не загружаются автоматически и исключены из Git.

Для собственного видео используйте плоский прямоугольный объект с различимыми
деталями: например, книгу с рисунком на обложке или открытку с текстом.
Первый кадр должен быть крупным, резким и показывать все четыре угла.
После этого перемещайте объект, поворачивайте его, меняйте расстояние и умеренно
наклоняйте. На несколько кадров полностью уберите объект, затем верните его,
чтобы проверить LOST и восстановление. Снимайте при равномерном свете, без бликов.

Из корня проекта:

```powershell
python main.py --input data/test_1.mp4 --output results/test_1_tracked.mp4 --label Book
```

Повторите для остальных видео. Для каждого сохраните выбранные углы, CSV, JSON
и несколько кадров результата. Запишите реальные условия съёмки и наблюдения
в таблицу основного README. Не подменяйте эти испытания генератором `demo.py`.
