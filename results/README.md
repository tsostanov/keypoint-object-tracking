# Результаты

Приложение сохраняет рядом с выходным видео:

- `<имя>_frames.csv`: статистику каждого кадра;
- `<имя>_summary.json`: сводку и параметры запуска;
- `<имя без суффикса _tracked>_selection.json`: углы при ручном выборе.

Например, для `test_1_tracked.mp4` это `test_1_tracked_frames.csv`,
`test_1_tracked_summary.json`, `test_1_selection.json`.
При загрузке через `--selection` исходный JSON не перезаписывается.

Видео и статистика обычных запусков в корне `results/` исключены из Git.
Для отчёта сохраняются GIF, изображения и измерения проверки в `videos/`,
а также синтетический пример в `demo/` с обработанным MP4 размером около 1,3 МБ.
Обработанные реальные видео и WebM-копии остаются локальными.

## Добавленные видео

Три варианта сцены с Моной Лизой и ролик с готовой разметкой проверены 21.10.2026.
В [videos/README.md](videos/README.md) находятся метрики, примеры кадров и команды запуска.
Три [GIF-примера](videos/README.md#gif-для-просмотра-на-github) доступны прямо на GitHub
и встроены в основной README. Обновить их можно командой `python make_gifs.py`
после установки `requirements-preview.txt` и обработки трёх исходных видео.
Исходники собраны в `data/videos/`, результаты в `results/videos/`.
Для просмотра в VS Code используйте H.264-копии в `results/videos/playback/`:
например, `mona-lisa_tracked.mp4`. Их можно обновить скриптом `prepare_previews.py`.
В новых результатах видны все ключевые точки, совпадения и inlier.
При неудачном поиске ORB используется сопровождение LK. Старые метрики
и примеры до этого изменения сохранены в `results/videos/baseline/`.

## Синтетический пример

Это результат запуска исходного ORB-трекера до добавления FLOW
**на сгенерированном ролике**, а не съёмка объекта и не материал преподавателя.
Дата проверки: 17.10.2026.

- [Обработанное видео](demo/synthetic_tracked.mp4)
- [Четыре кадра результата](demo/preview.jpg)
- [Покадровая статистика](demo/synthetic_tracked_frames.csv)
- [Сводка запуска](demo/synthetic_tracked_summary.json)
- [Проверка по известным углам](demo/evaluation.json)
- [Исходные углы](demo/synthetic_selection.json)
- [Истинные углы каждого кадра](demo/synthetic_ground_truth.json)

Воспроизведение из корня: `python demo.py`. Исходный ролик будет заново создан
локально. Чтобы сохранить зафиксированные метрики, используйте другой каталог:
`python demo.py --directory results/demo_local`.
