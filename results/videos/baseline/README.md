# Проверка до добавления FLOW

Здесь сохранены измерения, покадровая статистика, сводки и примеры кадров
исходного поиска ORB + RANSAC от 21.10.2026. Оптический поток и отображение
всех ключевых точек тогда не использовались.

Исходная доля TRACKING: 35,19% для `mona-lisa.avi`, 31,78% для `mona-lisa-blur.avi`
и 29,26% для `mona-lisa-blur-extra-credit.avi`. На образце `simple_track.avi` она равна 24,10%.
Подробности находятся в [evaluation.json](evaluation.json).

Пути к MP4 внутри старых JSON относятся к прошлому запуску: эти видео в родительской
папке уже заменены новыми результатами. Старые локальные WebM-копии сохранены здесь.
Актуальные результаты и сравнение находятся в [основном отчёте](../README.md).
